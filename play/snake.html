Snake

Python, turtle graphics · 2023 · Source on GitHub

This game needs a keyboard and a mouse, so it only runs on a laptop or desktop.

Loading.

Playing

  • Steer with W A S D or the arrow keys.
  • To pick a mode, click Normal, Mines or Walls during the countdown. The hint on the board about typing it in a terminal is older than the buttons.
  • High scores are kept in this browser, in the same text files the game writes on a desktop.

How it runs

This is Snake_v8.py exactly as it is on GitHub, run by CPython 3.11 compiled to WebAssembly (Pyodide), with the standard library's own turtle.py. It is 3.11 because that was current when I wrote it, and the game passes floats to random.randint, which Python stopped accepting in 3.12. The browser has no Tk, so a small stand-in for tkinter draws the canvas on this page. The game asks that canvas what lies under the snake's head, and the stand-in answers with the same overlap tests Tk uses, ported from Tk's C source.

Note: an LLM wrote the backend required for this to be playable online. I don't have the time nor the skillset to do something like that. I did, however write the code for the game myself.
