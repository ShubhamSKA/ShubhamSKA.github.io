Minesweeper

Python, in the terminal · 2023 · Source on GitHub

This game needs a keyboard, so it only runs on a laptop or desktop.

Loading.

Playing

  • Type a level, Easy, Medium, Hard, Insane or Custom, and press Enter.
  • Each turn asks for the column (x) and then the row (y) of the square to open, counting from 1 at the top left.
  • Typing end as the x coordinate quits.

How it runs

This is minesweeper.py and functions.py exactly as they are on GitHub, run by CPython 3.11 compiled to WebAssembly (Pyodide). The console is xterm.js, so the ANSI escape codes the game prints to rewrite its prompts behave as they do in a real terminal, and os.system('cls') clears it.

Note: an LLM wrote the backend required for this to be playable online. I don't have the time nor the skillset to do something like that. I did, however write the code for the game myself.
